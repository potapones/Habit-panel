# Терминал баланса

Личный трекер привычек. Работает как приложение на телефоне, без интернета и без аккаунтов. Все данные хранятся только в браузере устройства.

## Файлы

Все шесть файлов лежат в корне, без папок: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`.

## Установка через GitHub Pages

1. На github.com нажми **New repository**. Название нейтральное, например `habit-panel`. Видимость **Public**. Нажми **Create repository**.
2. На странице пустого репозитория нажми **uploading an existing file**. Загрузи все шесть файлов (с телефона: выбери их через «Choose your files»). Нажми **Commit changes**.
3. Открой **Settings → Pages**. В блоке **Build and deployment** выбери **Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
4. Через 1–2 минуты обнови страницу настроек. Появится ссылка вида `https://твой-ник.github.io/habit-panel/`.
5. Открой ссылку в Chrome на Android, затем меню **⋮ → Установить приложение** (или «Добавить на главный экран»).

## Перенос данных из версии в Claude

В версии в Claude: вкладка **ДАННЫЕ → Скачать JSON**. В приложении: **ДАННЫЕ → Загрузить JSON**. Переносятся отметки, недели, заметки, настроение и фото.

## Как обновлять приложение

1. Замени нужный файл в репозитории (Add file → Upload files).
2. В `sw.js` подними версию: `const VERSION = 'v2';` и дальше по порядку.
3. Закрой и открой приложение на телефоне дважды: первый запуск скачивает обновление, второй его показывает.

## Важно

- Данные живут только в этом браузере. Удаление приложения или очистка данных Chrome стирает историю. Сохраняй JSON-копию раз в неделю, приложение само напомнит.
- Репозиторий публичный: в нём только код. Не загружай туда свои JSON-копии.
