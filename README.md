# BalanceOS

Личный трекер привычек. Работает как приложение на телефоне, без интернета и без аккаунтов. Все данные хранятся только в браузере устройства.

## Файлы

Шесть файлов приложения лежат в корне, без папок: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`. Этот README можно тоже положить в репозиторий.

## Что нового в версии 10

- Карточка привычки: нажми на иконку привычки или на уже выполненную привычку. Внутри тепловая карта за полгода, серии, процент за 30 дней и правка последних 7 дней.
- Отмена: после отметки тост «Отменить» на 5 секунд. Повторное нажатие больше не снимает отметку случайно.
- Количественные привычки: в правке привычки «Как отмечать → Количеством», с целью, единицей и шагом. Опыт идёт пропорционально прогрессу.
- «Итог дня»: настроение, главное за день, заметка и шаг на завтра одним листом. Шаг утром появляется на «Сегодня».
- Тренды на «Прогрессе»: выполнение по неделям, серия по зависимости, настроение и привычка месяца.
- Перки разделены на «Открытые» и «Дальше», у достижений полоски прогресса.
- Новые линейные иконки в стиле стекла, переключатель «Светлое / Тёмное / Как в системе», подсказки первого дня.

## Обновление уже установленного приложения

1. Сначала сохрани копию данных. В старой версии это вкладка **Настройки → Данные → Скачать JSON** (в самых старых **ДАННЫЕ → Скачать JSON**).
2. В репозитории на GitHub: **Add file → Upload files**. Загрузи все шесть файлов, они заменят старые с теми же именами. Нажми **Commit changes**.
3. Подожди 1–2 минуты, пока GitHub Pages обновит сайт (вкладка **Actions**, зелёная галочка).
4. Открой приложение, закрой и открой ещё раз. Первый запуск скачивает обновление, второй его показывает. Данные при этом остаются на месте.

Новая иконка и цвет заставки на рабочем столе Android обновляются не сразу: Chrome перепроверяет их сам, иногда в течение суток. Чтобы увидеть сразу, удали приложение с главного экрана и установи заново (**⋮ → Установить приложение**). **Перед этим обязательно скачай JSON-копию**: при удалении данные могут стереться. После установки загрузи копию через **Настройки → Данные → Загрузить JSON**.

## Первая установка

1. На github.com создай репозиторий, видимость **Public**.
2. **uploading an existing file** → загрузи все шесть файлов → **Commit changes**.
3. **Settings → Pages → Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
4. Через 1–2 минуты в **Settings → Pages** появится ссылка вида `https://ник.github.io/репозиторий/`.
5. Открой её в Chrome на Android → **⋮ → Установить приложение**.

## Перенос данных из версии в Claude

В версии в Claude: **Настройки → Данные → Скачать JSON**. В приложении: **Настройки → Данные → Загрузить JSON**. Переносятся отметки, недели, срывы, «Тяга», разборы, свои и удалённые привычки, порядок, имя, пол, тон, зависимость, плитки, тема, название и фото.

## Как выпускать следующие обновления

Заменяешь нужные файлы в репозитории и в `sw.js` поднимаешь версию: `const VERSION = 'v11';` и дальше по порядку. Без этого телефон может показывать старую версию из кэша.

## Важно

- Данные живут только в этом браузере. Удаление приложения или очистка данных Chrome стирает историю. Сохраняй JSON-копию раз в неделю, приложение само напомнит.
- Репозиторий публичный: в нём только код. Не загружай туда свои JSON-копии.
